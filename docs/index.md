**Syllabus** is a Moodle activity that lets a teacher fill in a single structured course plan
with per-field autosave, submit it for coordination approval, and — once approved — the same
instance automatically renders three role-specific views: coordination/teacher, tutor (with
grading criteria and answer keys), and student (without them).
